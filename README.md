# 🎵 Aura — AI-Driven Mood-Adaptive Music Mobile App

## 🚀 À propos du projet
**Aura** est une application mobile innovante basée sur l'Intelligence Artificielle et la MusicTech. Elle génère et adapte de la musique en temps réel selon l'état émotionnel et les données biométriques de l'utilisateur.

## 🛠️ Stack Technique & Besoins
Nous recherchons un **Cofondateur Technique (CTO / Lead Developer)** pour concevoir le MVP :
- **Mobile :** Flutter ou React Native
- **Audio & IA :** Traitement du signal audio, intégration d'API / modèles de génération musicale
- **Backend / Cloud :** Firebase ou Node.js / Python
